# Biological project agent template

This starter template is for a biological modelling project using Claude Code, remote Ollama/Qwen, NeKo, MaBoSS, PhysiCell, literature review, independent scientific review, and reproducibility audit.

1. Read `docs/agentic-biomodelling-architecture.md`.
2. Fill the scientific-state Markdown files.
3. Check MCP server names with `/mcp`.
4. Replace the placeholder `pubmed` name in the literature agent.
5. Run `/agents` and confirm all six agents are visible.
6. Test a small NeKo workflow before the full pipeline.

This template does not modify the MCP server source repository.
